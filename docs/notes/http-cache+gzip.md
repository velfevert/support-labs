gzip сжимает тело ответа. Для согласования используются заголовки клиента и сервера: `Accept-Encoding` и `Content-Encoding`. Для сжатия должны быть соблюдены некоторые условия: клиент сообщает о поддержке gzip - отправляет свой заголовок, на сервере включена директива `gzip on;`, mime тип пригоден для сжатия, тело ответа превышает минимальный порог для сжатия и другие условия.

В блоке http объявляется директива `gzip_types text/css application/javascript` , она разрешает сжатие css и js.

Заголовок `Content-Encoding: gzip` означает, что nginx сжал тело ответа.

Получить размер css файла после сжатия
```
curl -s -o /dev/null \
-w 'Downloaded body: %{size_download} bytes\n' \
-H 'Host: static.local' \
-H 'Accept-Encoding: gzip' \
http://127.0.0.1/style.css
```

Вывод:
`Downloaded body: 98 bytes`

Изначальный размер CSS =88 байт, после сжатия =98 байт, потому что при сжатии добавляются служебные данные, которые могут увеличить размер крохотного файла.
