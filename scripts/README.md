Учебный bash скрипт, который выполняет бэкап каталога.
### Что реализовал

- Скрипт принимает два аргумента: исходную директорию и директорию для бэкапов.
- Проверяет количество передаваемых аргументов, существование исходной директории, возможность создания целевого каталога; для разных ошибок предусмотрены свои коды завершения
- Создает архив .tar.gz в указанном каталоге с временной меткой в имени в формате `YYYYMMDD-HHMMSS`. 
- При успешном создании архива скрипт завершается с кодом 0. В случае неудачи выводит сообщение в `stderr` и завершается с ненулевым кодом.
### Использование

Дать бит `x` скрипту и запустить:
```
sudo chmod u+x backup.sh
./backup.sh /path/to/source /path/to/backup
```

Либо без изменения прав:
```
bash backup.sh /path/to/source /path/to/backup
```

Созданный архив:
`/tmp/backups/backup-20261031-011319.tar.gz`
